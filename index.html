//Research Highlights

Self-Improving Agents: Memory & Continual Learning

How can agents turn experience into knowledge that makes the next task easier?

  • Meta-optimized agent memory. At Meta FAIR, I built a loop in which a meta agent reads full task trajectories and rewrites how an agent saves what it learned to files and loads it before the next task. The discovered designs beat the best hand-written memory by +12.8 points and summary-based compaction by +16.0, while using the least context. TODO: confirm Meta disclosure [P1]
  • Learning to take notes with RL. NoteTaker trains a dedicated notebook model, crediting each memory update only with the rewards of later tasks it could affect. A 9B notebook model outperforms Fable-5.1 in the same role on AppWorld Test-Challenge (25.8% vs. 23.0%) and generalizes to 5× longer task streams and unseen task models. TODO: confirm final numbers [P2]
  • Memory in weights. Generative Adapter compiles context into adapter weights in a single forward pass, improving StreamingQA F1 by 63.5% over fine-tuning. [P5]
  • Memory in retrieval. Dense X introduced propositions as a retrieval unit, now integrated into LangChain and LlamaIndex. [P7]
Meta-Optimization · FAIR 2026 NoteTaker · preprint Generative Adapter · ICLR'25 Dense X · EMNLP'24

RL Post-Training & Reward Design

Post-training optimizes proxies that models learn to game. I study when rewards get hacked and how to design ones that don't.

  • Reward hacking in factuality RL. Continuous factuality rewards can be gamed by making fewer or vaguer claims. RL with a binary retrieval-augmented reward cuts long-form hallucination by 39.3% and teaches calibrated abstention (44.4% fewer wrong answers on PopQA), without hurting instruction following, math, or coding. [P3]
  • Reducing regurgitation. ParaPO trains models to prefer paraphrases over memorized pre-training text, reducing verbatim reproduction while keeping famous quotations available on request. [P4]
  • Measuring copying. CopyBench shows that alignment can reduce literal copying while increasing non-literal copying of plots and characters. [P6]
Binary RAR · ICML'26 ParaPO · COLM'25 CopyBench · EMNLP'24
